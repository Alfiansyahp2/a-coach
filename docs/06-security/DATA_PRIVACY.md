## 1. Athlete Data Ownership
* Athletes maintain 100% ownership of their training plans and activity data.
* The platform does not sell, broker, or aggregate user data for advertising purposes.

## 2. Strava API Agreement Compliance
* The platform honors all privacy settings set by the user on Strava.
* If a user disconnects their Strava account, all associated tokens and synced activities are marked for deletion or deactivated per user preference.
