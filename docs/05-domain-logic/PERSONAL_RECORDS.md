## 1. Standard Distance Benchmark Categories
* **1K Benchmark:** Fastest 1,000 meters.
* **5K Benchmark:** Fastest 5,000 meters.
* **10K Benchmark:** Fastest 10,000 meters.
* **Half Marathon Benchmark:** 21,097.5 meters.
* **Marathon Benchmark:** 42,195.0 meters.
* **Longest Single Distance:** Greatest continuous distance recorded in a single activity.

## 2. Ingestion & Validation Rules
An activity is eligible for a PR category if its total distance meets or exceeds the benchmark distance ($pm 2\%$ margin). PRs store the achieved date and activity ID reference.
