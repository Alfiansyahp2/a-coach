## 1. Breakpoint Grid Specification
* **Mobile (< 768px):** Single-column layout. Sidebar converts to fixed bottom navigation dock. 7-day calendar converts to swipeable horizontal day scroller.
* **Tablet (768px - 1024px):** Collapsed icon-only sidebar. Calendar displays 7-day compact grid.
* **Desktop (1024px - 1440px):** Full 240px sidebar. Full 7-column calendar grid with simultaneous analytics panels.
* **Ultra-wide (> 1440px):** Content capped at 1280px (`max-w-7xl`) centered with balanced gutters.
