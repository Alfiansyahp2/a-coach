## 1. Commit Message Convention (Conventional Commits)
All commit messages must follow the format: `<type>(<scope>): <description>`
* `feat(planner):` Add drag-and-drop workout rescheduling.
* `fix(strava):` Auto-refresh token if within 5 minutes of expiration.
* `docs(architecture):` Establish C4 sequence diagrams in 03-architecture.
* `style(theme):` Adjust obsidian surface tokens to #12151D.
* `test(crypto):` Add AES-256-GCM auth tag verification tests.
